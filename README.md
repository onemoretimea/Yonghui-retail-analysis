# Yonghui-retail-analysis

零售企业经营分析｜永辉超市商业模式失效探究（对标胖东来）

## 📌项目背景

永辉曾经依靠生鲜低价模式成为国内头部商超企业，近年营收持续下滑、连续亏损。
本项目使用 SQL 完成财报数据清洗、衍生业务指标计算，使用 Tableau 搭建交互式经营看板，
从营收拆解、盈利结构、单店效率、库存周转、区域经营多维度定位企业经营问题，对标胖东来成功模式总结经营启示。
另附市场视角模块：用 CSMAR 日/月个股交易数据（TRD_Dalyr / TRD_Mnth）分析股价对"模式失效"与"胖东来式转型"的定价。

## 业务研究问题

1. 永辉营收下滑，是关店带来的影响，还是存量门店经营能力恶化（同店效应）？
2. 企业毛利率维持尚可，为什么持续大额亏损？固定成本与费用压力来源？
3. 单店盈利、生鲜库存周转、跨区域扩张存在哪些结构性短板？
4. 对比胖东来，两者商业模式底层差异与借鉴启示。
5. （市场模块）资本市场如何为转型定价？事件窗口是否有显著超额反应？

## 🛠工具栈

- **SQL (MySQL 8.0+)**：数据清洗、窗口函数计算业务 KPI（同店效应、单店指标）
- **Tableau**：交互式可视化仪表盘（搭建步骤见 `tableau_workbook/tableau_build_guide.md`）
- **数据源**：
  - 永辉超市（601933）2019-2024 年报、2025 三季报（营收/毛利/三费/存货/门店/分地区）
  - 胖东来经营数据来源于公开新闻报道（非上市公司，仅课程分析用途）
  - 股价数据：CSMAR 日个股回报率（TRD_Dalyr，2020-01-02 ~ 2024-12-31）、月个股回报率（TRD_Mnth，2019-01 ~ 2025-10）

## 🔍核心分析结论

1. **营收拆分**：2020-2021 依靠新开门店拉动收入，掩盖存量门店经营下滑；2023 同店效应 -85.6 亿是当年下滑主因；
   2024 大规模关闭低效门店（净关 225 家），留存优质门店同店效应转正（+66.3 亿），单店营收回升至 8,719 万元。
2. **盈利剪刀差**：毛利率 5 年稳定在 18.7%-21.6%，但收入收缩带来固定成本刚性，
   三费费用率从 19.0% 爬升至 23.7%，2024 年毛利 138.2 亿被三费 159.9 亿完全吞噬，造成持续净亏损。
3. **运营短板**：生鲜模式库存周转天数长期高于 50 天（2023 峰值 55.2 天），损耗和资金占用压力大；
   跨区域扩张下高营收区域（华西+西南约 35%）毛利率反而低于华北，规模优势没有兑现。
4. **对标启示**：胖东来坚持区域深耕（14 家店、单店产出约 8.6 亿元，为永辉的 ~10 倍）、员工激励（月薪 9,886 元、流失率 5%）、
   线下用户粘性；永辉早期盲目全国扩张，重规模轻单店质量。
5. **市场反应**（CSMAR 实测）：2021 年股价 -43.6% 与首亏同步；2024 年全年 +124.8%——
   2024-05-31 调改宣布后短窗口 +6.7%，2024-09-23 名创优品入主后 [-1,+7] 窗口 +61.3%，市场认可"质量转型"叙事。

## 💡业务建议（财务BP视角）

1. 持续关停低效门店，巩固存量优质门店的经营产出（2024 同店转正已验证方向）；
2. 优化运营费用结构，缓解固定成本刚性（租赁/折旧/人工随收入等比收缩）；
3. 改善生鲜供应链，降低库存周转天数至 45 天以下，减少生鲜损耗；
4. 参考区域深耕策略，优先做单店质量提升而非盲目扩张门店数量。

## 数据口径与数据字典

| 字段 | 口径 |
|---|---|
| revenue | 营业总收入（元），来自年报 |
| cogs / gross_margin | 营业成本；毛利率 = (营收-营业成本)/营收。2019-2020、2024 为披露原值，2021-2023 按披露毛利率还原 |
| selling/admin/finance_exp | 销售/管理/财务费用（元） |
| net_profit | 归属于母公司股东的净利润（元） |
| inventory | 年末存货（元）；库存周转天数 = 365×平均存货÷营业成本 |
| stores_end | 年末门店数（家）：911/1017/1057/1033/1000/775（2019-2024） |
| 同店效应拆解 | 假定营收 = 上年营收÷上年年末门店数 × 本年年末门店数；门店数效应 = 假定营收-上年营收；同店效应 = 本年营收-假定营收；ΔRev = 两者之和（恒等式自检见 02 脚本） |
| 区域面板 | 2024 为年报"主营业务分地区"披露口径（华西 123.3 亿/18.25%、西南 117.6 亿/17.41%、华中 52.1 亿、华南 28.9 亿等）；2020-2023 为按年报结构回溯的估算值（is_estimated=1），仅课程分析用途 |
| 胖东来 | 非上市公司，销售额/净利润/门店来自公开披露与新闻报道 |
| 股价 | CSMAR TRD_Dalyr/TRD_Mnth 清洗而来；日收益率 = 收盘价环比；累计收益基期为 2020-01-02（日）/ 2019-01（月） |

**主要数据来源**：永辉超市历年年度报告（巨潮资讯/公司官网）、2025 年第三季度报告、
腾讯自选股/东方财富财务数据接口（交叉核验）、胖东来官网销售数据及公开报道、CSMAR 数据库。
