# Yonghui-retail-analysis
Yonghui retail data analysis｜SQL+Tableau program，compared to Pang donglai business model
# 零售企业经营分析｜永辉超市商业模式失效探究（对标胖东来）

## 📌项目背景
永辉曾经依靠生鲜低价模式成为国内头部商超企业，近年营收持续下滑、连续亏损。
本项目使用SQL完成财报数据清洗、衍生业务指标计算，使用Tableau搭建交互式经营看板，从营收拆解、盈利结构、单店效率、库存周转、区域经营多维度定位企业经营问题，对标胖东来成功模式总结经营启示。

### 业务研究问题
1. 永辉营收下滑，是关店带来的影响，还是存量门店经营能力恶化（同店效应）？
2. 企业毛利率维持尚可，为什么持续大额亏损？固定成本与费用压力来源？
3. 单店盈利、生鲜库存周转、跨区域扩张存在哪些结构性短板？
4. 对比胖东来，两者商业模式底层差异与借鉴启示。

## 🛠工具栈
- SQL(Mysql)：数据清洗、窗口函数计算业务KPI（同店效应、单店指标）
- Tableau：交互式可视化仪表盘
- 数据源：永辉上市公司公开年报；胖东来经营数据来源于公开新闻报道（非上市公司，仅课程分析用途）

## 🔍核心分析结论
1. **营收拆分**：2020‑2021依靠新开门店拉动收入，掩盖存量门店经营下滑；2023‑2024大规模关闭低效门店，留存优质门店同店经营能力有所修复。
2. **盈利剪刀差**：毛利率保持稳定，但收入收缩带来固定成本刚性，运营费用持续吞噬毛利，造成持续净亏损。
3. **运营短板**：生鲜模式库存周转天数长期高于50天，损耗和资金占用压力大；跨区域扩张，但高营收区域没有带来更高毛利，规模优势没有兑现。
4. **对标启示**：胖东来坚持区域深耕、员工激励、线下用户粘性；永辉早期盲目全国扩张，重规模轻单店质量。

## 💡业务建议（财务BP视角）
1. 持续关停低效门店，巩固存量优质门店的经营产出；
2. 优化运营费用结构，缓解固定成本刚性；
3. 改善生鲜供应链，降低库存周转天数，减少生鲜损耗；
4. 参考区域深耕策略，优先做单店质量提升而非盲目扩张门店数量。
